# Synthetic-data application workflow

## Overview

This directory provides a public, synthetic-data version of the HIV application in **"Wilcoxon Random Forests for Robust Distributional Prediction".** The individual-level clinical data analyzed in the manuscript are not publicly distributed because access is governed by the participating cohort network and applicable data-use agreements. This repository includes a synthetic cohort with the same variable structure and public analysis code that demonstrates the computational workflow. Results obtained from the synthetic cohort will *not* numerically reproduce the confidential-data results in the manuscript.

## Generating synthetic data

To ensure the computational reproducibility of our methods, we have provided synthetic datasets (`synth_dat1.csv` -- `synth_dat5.csv`). The synthetic data sets were generated from the original data using the CRAN package `synthpop` (version 1.9-2) to generate the synthetic data. We used the `cart` method to generate the datasets. We generated 5 independent data sets, but only `synth_dat1.csv` was used for analysis.

Because these are synthetic data, the estimated threshold probabilities, Brier scores and distributional scores generated by running these scripts differ from the exact numerical results in the manuscript. However, the R codes execute the exact same pipeline.

## Data dictionary

The generated synthetic datasets preserves information of the 10 covariates and 2 outcomes of interest. The original cohort data does not have missingness, and so do the synthetic ones. To match the size of the original analysis cohort, we let the canonical public synthetic cohort contain 11,070 observations. The data dictionary of the synthetic datasets is:

| Name | Type | Notes |
|-------------------|-------------------|----------------------------------|
| `art_regimen` | Categorical | Antiretroviral therapy (ART) regimen: NNRTI-based, INSTI-based, PI-based, Other |
| `site` | Categorical | Study site: Argentina, Brazil, Chile, Honduras, Mexico, Peru |
| `male_y` | Binary | Whether the participant's sex at birth is male (1) or female (0) |
| `age_art` | Continuous | Age when receiving the ART: must be adults. |
| `year_art` | Continuous | Year when receiving the ART; integers, treated as continuous. |
| `base_VL` | Continuous | Baseline viral load; integers, treated as continuous. All baseline viral load must be above the assay detection limits. |
| `base_cd4` | Continuous | Baseline CD4 cell count; integers, treated as continuous. |
| `out_VL` | Ordinal discrete | Outcome; 6-month viral load. All 6-month viral load \<80 copies are encoded as 79 for simplicity, but they do not necessarily take value of 79. |
| `months_to_VL` | Continuous | Months from ART initiation to the measurement of 6-month CD4 and viral load. |
| `out_cd4` | Continuous | Outcome; 6-month CD4 cell count; integers, treated as continuous. |
| `prior_aids` | Binary | Whether the participant has prior AIDS-defining clinical events (1 for yes). |
| `infmode` | Categorical | Mode of infection: Heterosexual contact, Homosexual contact, Other, Unknown. |

## Analysis plan

### 6-month CD4 cell count

We apply the WRF and the quantile regression forest (QRF) to estimate the threshold probabilities $P(\text{CD4} \leq 200, 350, 500 \mid \mathbf{X})$ for 6-month CD4 cell counts. The two forest methods differ only in splitting criterion and both used `1-exp(-1)` subsampling, minimum node size of 5 and `mtry = 3`.

We use 10-fold cross validation, and for both models, we report:

-   Brier scores for
    -   `P(6-month CD4 <= 200 | X)`,
    -   `P(6-month CD4 <= 350 | X)`,
    -   `P(6-month CD4 <= 500 | X)`;
-   mean CRPS;
-   median CRPS;
-   Cramér–von Mises (CvM) calibration statistic;
-   calibration plots at the three thresholds.

We also fit the WRF to the full synthetic cohort and plot conditional CDFs for two prespecified reference profiles. To parallel the manuscript, hold other variables at synthetic-cohort medians or modes for `synth_dat1.csv`, set:

-   advanced-disease profile: baseline CD4 = 200 cells/$\mu$L and baseline VL = `10^6` copies/mL;
-   less-advanced profile: baseline CD4 = 500 cells/$\mu$L and baseline VL = `10^4` copies/mL.

### 6-month HIV viral load

We apply the WRF to estimate the threshold probability $P(\text{VL} < 80 \mid \mathbf{X})$ for 6-month ordered HIV viral load, using the same forest construction setting as for 6-month CD4 except for minimum node size of 20. We report the 10-fold cross validated Brier score.

We also fit the WRF to the full synthetic cohort and plot conditional CDFs for the same two prespecified reference profiles.

Additionally, we compare the WRF results with:

1.  an uninformative prevalence model.
2.  logistic regression for `I(VL < 80)`, using restricted cubic splines for continuous predictors; due to high skewness, we consider the square root of baseline CD4 and base 10 logarithm of baseline viral load.
3.  a classification random forest fitted directly to `I(VL < 80)`, using `1-exp(-1)` subsampling, `mtry = 3`, minimum node size of 20 and the same randomization seed as the WRF model.

The results of the logistic regression and the classification random forest are both obtained from 10-fold cross-validation, with the same random index sets.

## Proposed directory contents

In `data` folder: `synth_dat1.csv` to `synth_dat5.csv` are the generated synthetic datasets; only `synth_dat1.csv` is used for analysis.

In `R_scripts` folder:

| File | Notes |
|------------------------------------|------------------------------------|
| `application_cd4.R` | Codes for 6-month CD4 analysis, including the R codes for generating the calibration plot and the predicted CDF for two reference profiles. |
| `application_vl.R` | Codes for 6-month HIV viral load analysis, including the R codes for comparing the WRF with logistic regression and classification random forest, and the predicted CDF for two reference profiles. |
| `generate_synthetic_data.R` | Generate the synthetic datasets in `data` folder. |

In `results` folder:

| File | Notes |
|------|-------|
| `cd4_cv_results.csv`    | Analysis results for 6-month CD4; 10-fold cross-validated results of the WRF and the QRF models, including Brier scores for $P(\text{CD4} \leq 200, 350, 500 \mid \mathbf{X})$, mean CRPS, median CRPS and CvM statistic.     |
| `cd4_qrf_vimp_summary.csv`    | Analysis results for 6-month CD4; results for variable importance based on OOB CRPS derived from the QRF model, including the original mean OOB CRPS, the mean OOB CRPS after permuting each covariate, and the percentage change in mean OOB CRPS after permutation.    |
| `cd4_wrf_vimp_summary.csv`    | Analysis results for 6-month CD4; same thing as `cd4_qrf_vimp_summary.csv`, but from the fitted WRF model.     |
| `vl_brier_comparison.csv`    | Analysis results for 6-month viral load; comparison of the 10-fold cross validated Brier scores from the WRF, an uninformative model, logistic regression and classification random forest.    |
| `vl_variable_importance.csv`    | Analysis results for 6-month viral load; results for variable importance based on OOB Brier scores derived from the fitted WRF     |
| `two_profiles.csv`    | The reference profiles used to predict conditional CDF; generated based on `synth_dat1.csv`.     |
| `Figure_cd4_calibration.pdf`    | Analysis results for 6-month CD4; the calibration plots derived from the fitted QRF and WRF.     |
| `Figure_cd4_ecdf.pdf`    | Plot for conditional CDF of 6-month CD4 predicted from the fitted WRF using the reference profiles `two_profiles.csv`.    |
| `Figure_vl_ecdf.pdf`    | Plot for conditional CDF of 6-month viral load predicted from the fitted WRF using the reference profiles `two_profiles.csv`.     |
